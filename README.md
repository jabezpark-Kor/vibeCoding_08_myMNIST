## 🌸 주요 기능

- 🐱 **귀여운 마스코트 반응**: 글씨를 쓸 때, 분석할 때, 정답을 맞혔을 때 몽실이가 생생하게 반응합니다.
- 🔢 **초고속 숫자 인식 (0~9)**: 브라우저 내부에서 실시간으로 글씨 특징을 분석하여 0.1초 만에 맞히고, 후보 확률 순위를 시각화합니다.
- 🇰🇷 **한글 & 복합 모드**: Tesseract.js OCR을 탑재하여 별도 백엔드 서버 없이 브라우저 내에서 한글 단어와 문자를 판독합니다.
- 🎯 **따라쓰기 퀴즈 & 폭죽 효과**: 제시된 미션 글씨를 맞히면 화려한 폭죽 파티클 축하가 펼쳐집니다.
- 🔊 **발음 읽어주기 (TTS)**: 인식된 글자를 귀여운 아기 목소리로 또박또박 읽어줍니다.
- 🎨 **모바일 & 터치 완벽 지원**: PC 마우스뿐만 아니라 스마트폰, 태블릿 터치펜 드로잉을 부드럽게 지원합니다.
- 📋 **결과 복사 & 도화지 이미지 저장 기능 제공**

## 🚀 로컬 실행 방법

별도의 서버 설치 없이 웹 브라우저에서 바로 실행할 수 있습니다.

1. 저장소를 클론(Clone)하거나 다운로드합니다.
2. `index.html` 파일을 더블 클릭하여 크롬이나 엣지 브라우저에서 엽니다.
